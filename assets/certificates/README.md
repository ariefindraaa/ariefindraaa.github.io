# assets/certificates/

Sertifikat, bukti HKI, dan dokumen pendukung lainnya (PDF atau gambar).

Saran penamaan file — gunakan huruf kecil dan tanda hubung:

```text
hki-multix.pdf
hki-kalkulator-resistansi.pdf
sertifikat-infinite-learning.pdf
sertifikat-lks-mekatronika.pdf
sertifikat-abu-robocon-2025.pdf
publikasi-plts-kkn-tre-ugm.pdf
```

**Sebelum upload, sensor dulu data sensitif:** NIK, alamat lengkap, nomor ijazah,
tanggal lahir lengkap, dan tanda tangan basah. Repository ini publik, jadi apa pun
yang di-upload bisa dilihat dan diunduh siapa saja.

File di folder ini belum otomatis ditautkan dari halaman mana pun. Setelah
di-upload, tautannya bisa ditambahkan di bagian Education & Achievements
pada `index.html`.

Panduan lengkap: lihat `ASSET_GUIDE.md` di root repository.
