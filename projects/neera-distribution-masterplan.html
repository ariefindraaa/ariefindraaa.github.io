Neera Island Distribution System Masterplan

Project overview

This study develops a long-term development plan for the electricity distribution system of Neera Island. Rather than solving a single operating condition, the objective was to produce a staged roadmap: what the network has to look like now, and how it has to grow over a ten-year horizon as demand increases across 11 districts.

The deliverable combined a technical model, a reliability assessment, and a cost estimate so that the plan could be discussed in both engineering and budgeting terms.

✅

Tooling note: this masterplan was built in ETAP 12.6, not DIgSILENT. DIgSILENT PowerFactory appears only in the final project on transient stability.

Problem statement

An island distribution network has to serve geographically spread districts with limited interconnection, while demand keeps growing. Planning each year in isolation leads to reactive, expensive reinforcement.

The study therefore had to answer three linked questions: where will the load be in ten years, which parts of the network will violate voltage or loading limits first, and what does it cost to stay ahead of that curve while keeping service reliability acceptable.

Scope & my role

  • Compiled the existing load inventory and the service area data for all 11 districts.
  • Projected demand growth across the ten-year planning horizon.
  • Built the distribution network model and single-line diagram in ETAP 12.6.
  • Ran load-flow studies for the base case and for the projected future years.
  • Identified voltage-profile and equipment-loading violations, and proposed staged reinforcement.
  • Evaluated system reliability using standard distribution indicators (SAIFI and SAIDI).
  • Prepared the budget estimate (RAB) for the proposed development stages.

Method & workflow

  1. Collect the baseline. Gather existing network data and the load inventory for each of the 11 districts.
  2. Forecast demand. Project the load growth over the ten-year horizon to define the planning target for each stage.
  3. Model the network. Build the distribution system in ETAP 12.6, including feeders, transformers, and the single-line configuration.
  4. Run load-flow studies. Analyse the base case and each future planning year to obtain voltage profiles and equipment loading.
  5. Screen for violations. Flag the buses and branches that fall outside acceptable voltage or loading limits as demand grows.
  6. Plan the reinforcement. Define the network additions and upgrades needed per stage so the system stays within limits across the horizon.
  7. Assess reliability. Evaluate SAIFI and SAIDI to check that the proposed configuration improves service continuity, not just capacity.
  8. Estimate the cost. Build the budget estimate for the staged plan, arriving at a total in the order of USD 14 million.

Lessons learned

  • Masterplanning is a forecasting exercise as much as an electrical one — the growth assumption drives nearly every downstream decision.
  • Staging the investment matters: splitting reinforcement into periods makes a large programme financially realistic.
  • Reliability indices translate engineering work into language that non-technical stakeholders actually respond to.
  • Keeping the ETAP model, the load spreadsheet, and the cost estimate consistent with each other required disciplined version control of the input data.
