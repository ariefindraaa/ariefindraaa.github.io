# Portfolio Content Audit & Rekomendasi

Dokumen ini sengaja dipisah dari halaman utama agar portofolio publik tetap terlihat profesional, sementara catatan strategi dan kekurangan konten tetap tersimpan rapi di repository.

## Strategi tema yang dipakai sekarang

**Tema utama:** profesional untuk fresh graduate Electrical Engineering Technology dengan positioning utama pada:

1. **Renewable Energy / PV EPC** — paling direkomendasikan karena ada pengalaman Dekatama, PLTS KKN, PLTS Trainer, BCS, PJUTS, dan PATS.
2. **Power System / Protection** — kuat untuk posisi utility, consultant, atau design engineer karena ada ETAP Neera, ETAP Lombok, dan Tugas Akhir stabilitas transien.
3. **Electrical Site / MEP / Testing & Commissioning** — didukung pengalaman PT Patra Jasa di RTCT Pertamina.
4. **ML / Data for Power Systems** — diferensiasi unik, tetapi pasar kerjanya lebih niche.

## Konten yang belum ada dan sangat disarankan ditambahkan

1. **Foto profil profesional**
   Rekomendasi file: `assets/img/profile.jpg`
   Gaya: formal casual, background netral, pencahayaan terang, crop setengah badan.

2. **CV PDF final**
   Rekomendasi file: `assets/cv/Arief_Indra_Kusuma_CV.pdf`
   Setelah ada, tombol header bisa diganti dari `Hire / Contact` menjadi `Download CV`.

3. **Foto proyek lapangan**
   Prioritas foto:
   - PLTS KKN Lampung Selatan.
   - BCS Lombok.
   - PJUTS / PATS Sumbawa.
   - Dokumentasi RTCT Pertamina jika tidak melanggar kerahasiaan proyek.
   - GMRT ABU Robocon.
   - Trainer PLTS Off-Grid.

4. **Screenshot teknis proyek**
   Prioritas:
   - ETAP Neera: SLD / load flow / reliability summary.
   - ETAP Lombok: relay coordination / load flow.
   - DIgSILENT TA: skenario simulasi / data generation flow.
   - Power BI dashboard dari Patra Jasa jika aman untuk publik.
   - UI aplikasi Power Factor Correction.

5. **Certificate / proof links**
   Rekomendasi folder: `assets/certificates/`
   Bisa berupa PDF atau gambar, namun hindari data sensitif seperti NIK, alamat lengkap, nomor ijazah, atau tanda tangan yang tidak perlu.

6. **Detail pages per proyek**
   Untuk meniru portofolio teman secara lebih dekat, buat halaman seperti:
   - `projects/transient-stability-ieee39.html`
   - `projects/neera-distribution-masterplan.html`
   - `projects/lombok-protection-study.html`
   - `projects/plts-hybrid-kkn.html`
   - `projects/patra-jasa-rtct.html`

   Struktur yang disarankan per halaman:
   - Project overview.
   - Problem statement.
   - Scope / role pribadi.
   - Tools used.
   - Method / workflow.
   - Results.
   - Documentation gallery.
   - Lessons learned.

## Rekomendasi prioritas berikutnya

1. **Pakai versi sekarang sebagai portfolio utama dulu** karena sudah cukup profesional untuk dicantumkan di CV dan LinkedIn.
2. Tambahkan foto profil dan CV PDF agar terlihat lebih lengkap.
3. Buat 4 halaman detail pertama: TA, Neera, Lombok, PLTS KKN.
4. Tambahkan dokumentasi foto lapangan secara bertahap.
5. Untuk setiap lamaran, arahkan narasi portofolio sesuai role:
   - PV Engineer → tonjolkan PLTS, BCS, PJUTS, PATS, Dekatama, KKN.
   - Protection Engineer → tonjolkan Lombok, Neera, ETAP, TA.
   - MEP / Site Engineer → tonjolkan Patra Jasa, T&C, kabel, BoQ, AHSP.
   - ML / Data Engineer energi → tonjolkan TA, Infinite Learning, Power BI, Python.

## Catatan koreksi penting

- **DIgSILENT PowerFactory hanya ditampilkan untuk Tugas Akhir** sebagai sumber data simulasi IEEE 39-Bus.
- **Proyek Neera dan Lombok menggunakan ETAP**, bukan DIgSILENT.
- **PKL SMK** ditulis sebagai rencana 1 tahun yang terpotong COVID-19 menjadi ±3 bulan, dan pelaksanaannya tetap onsite/offline di Distrik Navigasi Kelas II Banjarmasin.
